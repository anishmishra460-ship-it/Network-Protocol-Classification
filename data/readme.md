Dataset Information

📌 About the Dataset

This project uses the KT_GameBox Dataset for Network Protocol Classification using Machine Learning.

The dataset contains network packet-level information collected from network traffic.

The original dataset is merged into a single CSV file for analysis and model development.

📊 Dataset Details

Dataset File: "KT_GameBox_All_Merged.csv"

The dataset contains the following important columns:

Column| Description
No.| Packet identification number
Time| Timestamp of the network packet
Source| Source IP address
Destination| Destination IP address
Protocol| Network protocol label
Length| Packet length
Info| Additional packet information

⚙️ Dataset Usage

The dataset is used for:

- Data understanding and cleaning.
- Exploratory Data Analysis (EDA).
- Feature engineering and feature selection.
- Network protocol classification.
- Machine learning model training and evaluation.

📂 Dataset Availability

The original dataset is not included in this GitHub repository due to dataset-sharing restrictions.

To run the project:

1. Obtain the original KT_GameBox dataset.
2. Merge the required dataset files into a single CSV file.
3. Save the merged file as "KT_GameBox_All_Merged.csv".
4. Upload the file to Google Colab.
5. Execute the project notebook.

Expected file location in Google Colab:

"/content/KT_GameBox_All_Merged.csv"
